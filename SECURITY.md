# Security Policy

## Reporting a Vulnerability

If you believe you have discovered a security vulnerability in **Monitoring Pinger**, please **do not open a public GitHub issue**.

All vulnerability reports must follow the Direction interministérielle du numérique (DINUM) vulnerability disclosure policy:

👉 [https://vdp.numerique.gouv.fr/p/Policy](https://vdp.numerique.gouv.fr/p/Policy)

This project is operated by the French State (Direction Interministérielle du Numérique – DINUM).

Thank you for helping us improve security.
